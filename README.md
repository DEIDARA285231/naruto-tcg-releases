# Naruto TCG Desktop: download

Simulatore fan-made **non ufficiale** del NARUTO CARD GAME per Windows: partite in solitario, contro l'AI e (presto) online.

## Installazione

1. Apri l'ultima versione nella sezione **[Releases](../../releases/latest)**.
2. Scarica il file `Naruto TCG Desktop_x.y.z_x64-setup.exe` e avvialo.
3. Non servono diritti di amministratore. Gli aggiornamenti successivi arrivano da soli all'apertura del launcher.

Windows SmartScreen può mostrare un avviso perché l'installer non ha un certificato di code signing commerciale:
*Ulteriori informazioni → Esegui comunque*. Gli aggiornamenti automatici sono comunque protetti da una firma digitale verificata dall'app.
